🔍 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

If you see TypeScript errors in editor:
   1. Save the file (Ctrl+S)
   2. Wait 2-3 seconds for TypeScript compilation
   3. Errors should disappear automatically

If frontend shows blank page:
   1. Check browser console (F12)
   2. Verify backend is running: curl http://localhost:5000/health
   3. Check network tab for API calls
   4. Clear browser cache and reload

If API calls fail:
   1. Verify API URL in frontend/.env
   2. Should be: VITE_API_URL=http://localhost:5000/api
   3. Check backend logs for errors
   4. Restart backend: Press 'rs' in backend terminal

Port Already in Use:
   For :5000:  npx kill-port 5000
   For :3000:  npx kill-port 3000
