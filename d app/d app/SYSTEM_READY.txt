🛠️ DEVELOPMENT TIPS

  • Frontend files: Save → Auto-reload in browser
  • Backend files: Save → Auto-restart server
  • No manual commands needed!

Debugging:
  • Backend logs visible in terminal
  • Frontend: Use browser DevTools (F12)
  • Check backend logs/error.log
  • Check backend logs/all.log

  • Use Postman: Import endpoints from docs/API.md

Port Issues:
  • Port 3000 busy: npx kill-port 3000
  • Port 5000 busy: npx kill-port 5000
  • Or change PORT in backend/.env
