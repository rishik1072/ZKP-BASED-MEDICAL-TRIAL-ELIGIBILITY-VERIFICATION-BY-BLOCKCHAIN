ESSENTIAL COMMANDS
═══════════════════════════════════════════════════════════════════════════

Install & Build:
  npm run setup:all              # Install all dependencies
  npm run build:circuits         # Compile Circom circuits (~5-10 min)
  npm run build:contracts        # Compile Solidity contracts

Development:
  npm run dev                    # Start both backend & frontend
  cd backend && npm run dev      # Backend only (port 5000)
  cd frontend && npm run dev     # Frontend only (port 3000)

Testing:
  npm run test:backend           # Unit tests for backend
  npm run test:circuits          # Circuit tests
  cd examples && node example.js # Run example scenarios

Deployment:
  npm run deploy:mumbai          # Deploy to Polygon Mumbai testnet
  npm run deploy:polygon         # Deploy to Polygon Mainnet

Build & Production:
  npm run build:all              # Build all packages for production
  npm run lint                   # Lint all code

API ENDPOINTS (Backend)
═══════════════════════════════════════════════════════════════════════════

ZKP Operations:
  POST /api/zk/generate-proof     → Generate proof from credentials
  POST /api/zk/verify-proof       → Verify proof locally
  POST /api/zk/store-on-chain     → Store on blockchain
  GET  /api/zk/result/:hash       → Get stored result
  GET  /api/zk/eligibility/:hash  → Check eligibility status

Blockchain:
  POST /api/blockchain/init       → Initialize blockchain service
  GET  /api/blockchain/config     → Get configuration

Health:
  GET  /api/health                → Check if backend is running

COMMON ISSUES & FIXES
═══════════════════════════════════════════════════════════════════════════

Circuit compilation fails:
  ✓ Install Circom: curl --proto '=https' --tlsv1.2 -sSf 
    https://sh.rustup.rs | sh
  ✓ Increase RAM: Use tmux or separate terminal
  ✓ Check disk space: Need 10GB+ free

Backend won't start:
  ✓ Port 5000 in use: npm run dev -- --port 3001
  ✓ .env missing: cp .env.example .env
  ✓ Dependencies: npm install in backend/

Frontend shows blank page:
  ✓ Backend not running: npm run dev in backend/
  ✓ VITE_API_URL wrong: Check .env in frontend/
  ✓ Clear cache: rm -rf node_modules && npm install

Proof verification fails:
  ✓ Wrong verification key: circuits/dist/VerifyEligibility.json
  ✓ Credential format wrong: Compare with examples/sample-credential.json
  ✓ Nonce mismatch: Use same nonce for generation & verification

Smart contract deployment fails:
  ✓ No MATIC: Get testnet MATIC from faucet (mumbai)
  ✓ Wrong network: Check POLYGON_RPC_URL in .env
  ✓ Gas too low: Increase gas estimate by 20%

SECURITY REMINDERS
═══════════════════════════════════════════════════════════════════════════

🔒 Do NOT:
  ✗ Commit .env file
  ✗ Share private keys
  ✗ Use same key for dev & production
  ✗ Store credentials in logs
  ✗ Skip testnet testing

✅ Do:
  ✓ Use environment variables
  ✓ Rotate keys regularly
  ✓ Use hardware wallet for production
  ✓ Enable 2FA on everything
  ✓ Backup private keys securely

🔐 Privacy by Design:
  ✓ Medical values never exposed
  ✓ Only eligibility status stored on-chain
  ✓ Poseidon hashing is one-way
  ✓ ZKP proves without revealing
  ✓ No raw patient data in blockchain
